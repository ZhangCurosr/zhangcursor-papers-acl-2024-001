# 论文速读：Improving-Event-Definition-Following-For-Zero-Shot-Event-Det

## 一句话总结
本文通过训练模型更好地遵循事件定义来提升零样本事件检测性能，构建了包含3000+事件类型和多样化定义的DivED数据集，并发现事件类型多样性与定义多样性是提升泛化能力的关键因素；在此基础上结合事件本体论信息与难负样本，微调的LLaMA-2-7B模型在ACE、M2E2和MEE三个基准上均达到SOTA，超越了GPT-3.5。

## 研究问题与动机
- **核心问题**：如何让模型在推理时仅凭事件定义就能准确识别未见事件类型的触发词？
- **现有方法不足**：
  1. 现有事件抽取数据集通常只关注少数事件类型的高质量样本，缺乏足够多的事件类型和多样化的定义，导致模型难以泛化到未见事件。
  2. 现有零样本事件检测方法多依赖封闭大模型（如GPT-3.5）提示或仅使用少量事件类型数据进行迁移学习，性能参差不齐且不可复现。
  3. 传统方法倾向于为已知事件类型生成更多相似样本，但未充分探索事件类型数量、定义多样性以及本体论信息对模型定义遵循能力的影响。

## 核心贡献（创新点）
1. **构建DivED数据集**：设计了自动数据生成流水线，生成包含3000+事件类型、每个类型10条多样化定义和10个样本的大规模数据集，弥补了传统事件抽取数据集在类型和定义多样性上的不足。
2. **系统分析数据成分影响**：首次系统研究了事件类型数量、定义数量、样本数量、事件本体论信息和难负样本对零样本事件检测性能的影响，揭示了多样性优于数量的规律。
3. **引入本体论与难负样本**：在事件定义中融入事件类型的父类/兄弟类信息，并使用兄弟事件作为难负样本，显著提升了模型对事件边界的理解和召回率。
4. **实现SOTA性能**：基于上述发现，在DivED和Geneva数据集上微调LLaMA-2-7B模型，在ACE、M2E2和MEE三个基准上均取得最优性能，以较小参数规模超越了GPT-3.5等大模型。

## 方法详解
**1. DivED数据集生成流水线**（五步流程）：
   - **Step1 事件类型检索**：从XPO-overlap获取约6000个带有本体论依赖树的事件类型名称，并手动过滤掉与测试集（ACE、M2E2、MEE）共享依赖树的事件。
   - **Step2 本体论感知定义生成**：给定一组同属一父节点的事件类型，引导模型同时生成简洁且能区分相似事件的定义。
   - **Step3 本体论感知样本生成**：基于事件定义和兄弟事件信息，为每个事件类型生成10个包含触发词的示例句子。
   - **Step4 定义扩展**：将初始定义 paraphrase 10次，获得多样化的定义表述。
   - **Step5 本体论剪枝**：计算同一本体树内两个事件类型间触发词的重叠率（精确字符串匹配），若重叠率超过阈值（0.5）则删除其中一个，保证事件类型和触发词的多样性。

**2. 数据成分影响分析实验**：
   - **事件类型缩放**：测试[200, 400, 800, 1600, 3200]个事件类型，发现200个事件类型在域外数据（ACE）上表现最佳，过多会导致过拟合。
   - **事件定义缩放**：测试每个事件1~10条定义，发现4条定义能在域内和域外均获得提升，更多定义有助于域外泛化。
   - **样本数量缩放**：在Geneva数据集上测试每个事件1~40个样本，发现10个样本已足够，超过10个反而因过拟合而性能下降。
   - **本体论信息**：在事件定义中输入父类和兄弟类事件名称，帮助模型理解事件层次结构。
   - **难负样本**：用兄弟事件类型构造负样本（输入句子中不含该事件，但类型与正样本相近），增强模型对相似事件边界的区分能力。

**3. 模型训练**：
   - 基座模型：LLaMA-2-7B。
   - 数据混合：使用DivED（200个事件类型）和Geneva（90个事件类型）的数据，每个事件类型提供10条定义、10个正样本和10个负样本（其中包含3个难负样本），并加入本体论信息。
   - 训练超参：batch size=96，学习率=2e-5，训练20个epoch。
   - 提示格式：输入包含事件类型、事件定义、事件本体论信息和查询文本，期望输出为形式化的触发词识别结果。

## 实验与结果
**数据集**：
- **自有数据集**：DivED（训练集3232个事件类型，验证集随机采样约50棵本体树共100个事件类型）。
- **评测基准**：ACE05、M2E2、MEE（均使用英文部分，按TextEE框架评估）。
- **基线模型**：ChatIE（多轮问答框架）、Gao et al.（提示工程优化）、GPT-3.5-Turbo、LLaMA-2-7B in Geneva（仅用Geneva训练）。

**主要结果**（Table 4）：
- **ACE**：Trigger ID F1 **34.2**（Prec. 46.7, Rec. 26.9），Trigger CLS F1 **29.1**（Prec. 36.7, Rec. 24.1）。
- **M2E2**：Trigger ID F1 **23.4**，Trigger CLS F1 **22.0**。
- **MEE**：Trigger ID F1 **27.1**，Trigger CLS F1 **26.0**。
- **平均F1**：Trigger ID平均28.2，Trigger CLS平均25.7，显著高于所有基线。

**最强结果与提升**：
- 在ACE上Trigger ID F1达到34.2，相比GPT-3.5（15.9）提升**18.3个百分点**，相比LLaMA-2-Geneva（22.2）提升**12.0个百分点**。
- 在三个基准上的平均性能均位列第一，以7B参数规模超越了千亿参数规模的GPT-3.5。

**消融实验**：
- **去本体论/去难负样本**（Table 3）：移除后Trigger ID F1从29.1降至19.4/25.3，Recall显著下降，说明本体论和难负样本能有效提高召回率。
- **仅用DivED vs 混合Geneva**（Table 5）：仅DivED已优于Geneva训练基线；混合后性能进一步提升，证明方法的可扩展性。
- **去除事件定义**（Table 6）：在DivED训练的模型性能下降52%（Trigger ID），而在Geneva训练的模型仅下降7%，表明DivED训练模型更依赖事件定义，即遵循定义的能力更强。

## 相关工作脉络
1. **ChatIE (Wei et al., 2023)**：将零样本事件检测转化为多轮问答，先识别事件类型再找触发词。本文方法直接使用定义和样本进行单轮生成，更高效且性能更好。
2. **Gao et al. (2023a)**：探索ChatGPT在事件抽取中的可行性，分析定义、示例和反事实示例的影响。本文与之类似，但进一步系统分析了数据规模和本体论信息的作用，并提供了开源的替代方案。
3. **Geneva (Parekh et al., 2023a)**：提供了大量人工标注的事件类型和样本，但事件类型数量有限。本文指出仅增加同类样本数量不如增加事件类型和定义多样性有效。
4. **Star (Ma et al., 2024)**：通过结构到文本生成来增强低资源事件抽取，侧重于生成更多相似样本。本文则从事件类型和定义多样性角度切入，两者互补。
5. **XPO-overlap / GLen**：提供了大规模事件本体知识库。本文利用其事件类型和依赖树作为数据生成基础，并进行了针对性的过滤和剪枝。

## 局限性与未来方向
- **局限性**：
  1. 数据完全由LLM自动生成，可能无法完全捕捉真实世界中复杂、专业的事件，存在分布偏移风险。
  2. 依赖完整的事件本体论信息和难负样本，在实际场景中可能难以获取。
  3. 扩展到更多语言或专业领域时，受限于基座模型（LLaMA-2）的知识和语言能力。
  4. 当前研究主要基于英文基准，跨语言泛化能力未验证。
- **未来方向**：
  1. 将数据生成方法迁移到其他低资源语言或专业领域（如生物医学），结合领域知识进行微调。
  2. 研究如何减少对显式本体论的依赖，或从小规模本体论中高效推导。
  3. 探索自动生成的数据与人工高质量数据的最佳配比，进一步提升模型鲁棒性。

## 研究启发与可借鉴点
1. **数据多样性优先于数据量**：在训练模型遵循新定义时，增加事件类型数量和定义表述多样性比单纯增加同类样本更有效，这一原则可迁移到其他零样本学习任务。
2. **利用层次结构信息增强边界理解**：将事件类型的父类/兄弟类信息嵌入定义，能有效帮助模型区分相似概念，该方法可推广至NER、关系抽取等需要精细区分的任务。
3. **难负样本的设计策略**：使用语义相近的兄弟事件作为负样本，比随机负样本更能提供判别信号，值得在其他分类/抽取任务中尝试。
4. **开源小模型可挑战闭源大模型**：通过精心设计的数据和训练策略，7B参数的开源模型能在特定基准上超越千亿参数闭源模型，为资源有限的研究团队提供了可行路径。
5. **系统化的数据成分分析**：论文对事件类型、定义、样本数量的缩放实验设计严谨，可作为类似研究中分析数据因素影响的参考模板。

## 关键术语表
- **零样本事件检测（Zero-shot Event Detection）**：在推理阶段给定未见事件类型的定义，要求模型从文本中识别出对应的触发词。
- **DivED数据集（Diverse Event Definition Dataset）**：本文自动生成的包含3000+事件类型和多样化定义的训练数据集。
- **事件本体论（Event Ontology）**：事件类型之间的层次依赖关系（如父子、兄弟关系），用于辅助模型理解事件语义边界。
- **难负样本（Hard-negative Samples）**：与正样本事件类型相近但不属于该事件的样本（如兄弟事件），用于增强模型的区分能力。
- **事件触发词（Event Trigger）**：文本中表示某个事件发生的关键词或短语，通常是动词。
- **指令遵循（Instruction Following）**：模型根据给出的文本指令（如事件定义）准确执行任务的能力。
- **触发词识别（Trigger ID）**：判断文本中是否存在某事件的触发词（二分类）。
- **触发词分类（Trigger CLS）**：在识别触发词的基础上，进一步确定其所属的事件类型（多分类）。
