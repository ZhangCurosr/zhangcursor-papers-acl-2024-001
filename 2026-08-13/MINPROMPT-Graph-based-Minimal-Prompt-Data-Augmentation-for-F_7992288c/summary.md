# 论文速读：MINPROMPT-Graph-based-Minimal-Prompt-Data-Augmentation-for-Few-shot-Question-Answering

## 一句话总结
本文提出 MINPROMPT，一种基于图的最小提示数据增强框架，通过在原始文本中构建句子图并利用近似最小支配集算法筛选信息最密集的句子，结合无监督问题生成策略合成高质量问答对，从而在少样本问答任务中以更高效率实现比肩或优于现有基线的 F1 表现。

## 研究问题与动机
1. **少样本 QA 微调数据稀缺**：传统监督学习依赖大量专家标注的问答对，获取成本高；少样本场景下微调数据极为有限（通常仅 16-128 个样本）。
2. **现有数据增强方法未能充分捕捉关键信息**：多数方法直接随机采样或全量使用原始文本，忽略了句子间的事实重叠关系，可能导致冗余训练或噪声引入。
3. **提升微调效率与泛化能力的需求**：在大模型时代，微调成本随数据量线性增长，需要从有限文本中精准提取最具代表性的事实句子，以最小计算代价获得最大信息覆盖。

## 核心贡献（创新点）
1. **提出基于图的最小数据增强框架**：通过构建句子级共指图并求解近似最小支配集，自动筛选出覆盖最多实体信息的句子子集，区别于传统随机采样或全量使用原始文本的做法。
2. **设计无监督模板化问题生成策略**：将选定事实句子转换为“Wh+B+A+?”格式的问答对，并利用 SQuAD 语料中的实体类型二元分布作为启发式先验选择疑问词，而非依赖大型生成模型。
3. **理论保证与高效算法**：给出贪心支配集算法的近似比上界为 ln Δ + 2（Δ 为最大度），时间复杂度 O(E log V)，在 NP-Complete 问题上实现了实用可行的近似解。
4. **系统验证与消融分析**：在 MRQA 2019 八个基准数据集上全面验证 MINPROMPT 的有效性，并通过与随机采样变体、无监督域自适应方法等的对比，证明其组件的必要性与优越性。

## 方法详解
1. **命名实体识别与实体类型标注**：使用 spaCy NER 管道从原始文本中提取所有实体提及及其类型（如人名、地点、组织等），为后续共指关系构建提供基础。
2. **句子图构建**：将每句话作为节点，若两句话共享至少一个实体则在它们之间建立边，形成反映上下文事实关联的图结构。
3. **近似最小支配集算法**：采用贪心策略，迭代选择当前度数最高的节点加入支配集，并移除该节点及其邻居，直至所有节点被覆盖；算法时间与空间复杂度分别为 O(E log V) 和 O(V)。
4. **问题生成**：对选中的事实句子，根据其中实体类型选择疑问词（what/who/where 等），并按模板“Wh+B+A+?”重构问题，其中 A 为答案实体，B 为句子剩余片段；生成过程无需人工标注。
5. **提示式数据增强**：将原始微调样本与增强生成的问答对统一格式化为提示结构（Question: q, Answer: <mask>, Context: c），合并为最终训练集。
6. **训练损失函数**：总损失为原始样本损失 L^ori 与增强样本损失 L^aug 的加权平均，即 L(θ) = L^ori(θ) + λ L^aug(θ)，其中 λ 为平衡超参数，通过网格搜索确定。

## 实验与结果
- **数据集**：MRQA 2019 共享任务中的八个主流 QA 基准（SQuAD、TriviaQA、Natural Questions、NewsQA、SearchQA、HotpotQA、BioASQ、TextbookQA），分别采样 16、32、64、128 个训练样本构建少样本设置。
- **基线方法**：RoBERTa、SpanBERT、Splinter、FewshotQA、PMR，以及无监督域自适应方法 Qasar 和最近的数据增强方法 MQA-QG。
- **主要结果**：在几乎所有设置下，搭载 MINPROMPT 的 Splinter 与 FewshotQA 均取得更高平均 F1 分数与更低方差；例如 128 示例时 FewshotQA w/ MINPROMPT 在 SQuAD 上达到 80.5±1.4，在 TextbookQA 上达到 52.5±3.7，显著超越基线。相较于 Splinter 基线，MINPROMPT 平均提升约 8-9 个 F1 点（16 示例时）。
- **最强结果**：FewshotQA w/ MINPROMPT 在 TextbookQA 128 示例设置下取得 52.5±3.7 的 F1，较原始 FewshotQA 提升约 6.3 个点，且稳定性更好。

## 相关工作脉络
1. **FewshotQA (Chada & Natarajan, 2021)**：采用预训练编码器-解码器模型进行少样本 QA，本文在其框架上引入 MINPROMPT 数据增强，弥补其未充分利用原始文本知识的不足。
2. **Splinter (Ram et al., 2021)**：针对抽取式 QA 设计重复跨度选择预训练任务，本文将其作为骨干模型之一，验证 MINPROMPT 在预训练与微调结合场景下的增益。
3. **PMR (Xu et al., 2023)**：利用维基百科超链接构建机器阅读理解训练数据，本文方法不依赖外部链接资源，而是从纯文本中提取事实句子。
4. **MQA-QG (Pan et al., 2021)**：无监督多跳问题生成方法，本文聚焦单跳事实句子，通过图结构选择而非生成来扩大训练数据。
5. **Qasar (Assem et al., 2021)**：无监督域自适应抽取式 QA 框架，本文在微调样本更少的情况下（16-128 vs. 142-4,185）取得更好性能，凸显数据增强效率优势。

## 局限性与未来方向
- **NER 模块依赖**：Pipeline 性能受 spaCy NER 准确性制约，错误实体识别会传递至图构建与问题生成阶段。
- **实体重要性未加权**：所有共享实体平等处理，未区分关键实体与次要实体，可能影响句子选择质量。
- **提示模板人工设计**：当前 prompt 格式为固定规则，缺乏端到端自动化学习能力。
- **问题类型分布不均**：生成的 wh- 问题集中在 what/who/when，why/how 类长答案问题较少，可能影响泛化。
- **未来方向**：探索实体重要性加权机制、开发自动 prompt 模板学习算法、扩展至多跳问答与更复杂推理任务。

## 研究启发与可借鉴点
1. **图结构用于数据选择**：将自然语言文本建模为图并应用组合优化算法（如支配集）进行关键单元筛选，可迁移至摘要生成、知识蒸馏等领域。
2. **无监督问题生成结合类型先验**：利用大规模标注语料（如 SQuAD）中的实体类型-疑问词共现分布作为启发式规则，以低成本实现多样化问题生成。
3. **原始数据与增强数据加权融合**：通过超参数 λ 灵活平衡真实标注样本与合成样本的比例，缓解少样本过拟合风险。
4. **实验设计严谨**：在多个数据集、多种样本量及不同基线上进行全面对比，并结合消融实验与案例分析验证各模块必要性，值得学习。

## 关键术语表
- **最小支配集**：图中一个节点子集，使得图中任意节点要么属于该子集，要么与该子集内某节点相邻；本文用于选择覆盖最多事实信息的句子集合。
- **句子图**：以句子为节点、以共享实体为边构成的图结构，用于表征文本内部的事实关联性。
- **提示微调**：将任务输入格式化为带有特定模板（如 Question/Answer/Context）的序列，利用预训练模型进行高效微调的技术。
- **无监督问题生成**：无需人工标注数据，从已有文本中自动提取问题-答案对的方法。
- **共指消解**：识别文本中不同表达式（如代词、名词短语）指向同一实体 linguis tic 任务。
- **SQuAD**：Stanford Question Answering Dataset，大规模开放域阅读理解数据集，用于训练问题生成模型中的疑问词先验。
