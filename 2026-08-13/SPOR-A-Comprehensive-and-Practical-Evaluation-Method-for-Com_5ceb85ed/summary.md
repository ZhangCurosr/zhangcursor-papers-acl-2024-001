# 论文速读：SPOR-A-Comprehensive-and-Practical-Evaluation-Method-for-Com

## 一句话总结
论文提出 **SPOR**，一种针对 Data-to-Text 生成任务中组合泛化能力的综合评估方法，从系统性、生产力、顺序不变性和规则可学性四个维度对包括大语言模型在内的多种模型进行评测，发现所有模型在四个维度上均存在不足，且大模型虽有所改善但未根本消除缺陷。

## 研究问题与动机
1. **现有研究仅关注系统性单一维度**：Data-to-Text 领域的组合泛化研究局限于 Systematicity（处理训练 unseen 数据组合的能力），无法全面反映模型在实际应用中的组合泛化表现。
2. **缺乏对大语言模型（LLMs）的评估**：以往研究未将 LLMs 纳入评测，而随着 LoRA 等参数高效微调技术的发展，LLMs 应用于 Data-to-Text 成为可能，亟需评估其组合泛化能力。
3. **缺少综合性的评估框架**：语义解析、数学推理等领域已研究多种组合泛化表现，但 Data-to-Text 领域尚无同时覆盖多维度、无需额外人工标注的综合评估方法。
4. **实际应用需求驱动**：真实场景中输入数据组合数量庞大，模型需具备处理 unseen 组合、更长输入序列、任意输入顺序以及遵循复制规则等综合能力。

## 核心贡献（创新点）
1. **提出涵盖四个维度的组合泛化评估框架**：首次将 Systematicity、Productivity、Order Invariance、Rule Learnability 四个维度统一用于 Data-to-Text 生成任务的组合泛化评估，填补了该领域多维度评测的空白。
2. **设计基于重分配（repartition）的自动化数据集构建方法**：基于现有数据集（WebNLG、E2E）通过算法自动构造评测数据集，无需额外人工标注，显著降低评测成本。
3. **系统评测包括 LLMs 在内的多种模型**：将 T5-11b、Mistral-7b、Llama-2-13b 等大模型纳入 Data-to-Text 组合泛化评测，揭示大模型在该任务上的真实能力边界。
4. **揭示训练集顺序一致性的负面影响**：发现按文本中出现顺序排列训练数据的 Match 训练集会显著降低模型的顺序不变性，并损害整体性能，为数据构建提供重要启示。

## 方法详解
SPOR 包含四个评估方面，每个方面均通过数据集重构实现：

### 1. Systematicity（系统性）
- **定义**：处理训练期间未见过的数据单元组合的能力。
- **数据集构建**：
  - **Atom 集**：包含测试集中所有原子（数据单元），但不包含任何原子间的组合。
  - **Combination 集**：覆盖相同原子，但包含原子间的组合。
  - **算法 1**：从原始数据集 S 中随机选取样本，若其所有数据单元已被 Atom 覆盖且 Atom 中不含该样本的组合，则将其加入测试集，并将其单单元覆盖样本加入 Atom，多单元覆盖样本加入 Blocked。
  - **算法 2**：对 Blocked 中的样本，用其替换 Atom 中的样本以获得 Combination，确保原子总数不变且分布散度（Chernoff 系数）不超过阈值 r=0.02。
- **评估方式**：分别在 Atom 和 Combination 上训练模型，在测试集上评估，Performance on Atom 作为系统性指标，Performance on Combination 作为上界。

### 2. Productivity（生产力）
- **定义**：处理输入数据量超过训练时所见最大长度的能力。
- **数据集构建**：
  - 设定阈值 N ∈ {3, 4, 5}。
  - **Invisible 集**：仅包含数据单元数 ≤ N 的样本。
  - **Visible 集**：通过替换 Invisible 中的样本获得，包含数据单元数 > N 的样本，确保总单元数相同且分布散度 ≤ 0.02。
  - 测试集：所有数据单元数 > N 的样本。
- **评估方式**：分别在 Invisible 和 Visible 上训练，在测试集上评估，Invisible 上的性能作为生产力指标。

### 3. Order Invariance（顺序不变性）
- **定义**：当输入数据顺序改变时，输出文本保持数据忠实性和正确排序的能力。
- **数据集构建**：
  - **Original 训练集**：原始训练数据。
  - **Match 训练集**：对每个训练样本，按数据单元在参考文本中的出现顺序排列输入。
- **评估指标**：
  - **Fidelity（忠实性）**：输出包含的数据单元集合与输入完全匹配。
  - **Proper Ordering（正确排序）**：输出数据单元顺序与至少一个参考文本的顺序 Kendall 相关系数 k > 0。
  - **PBH（Both Have）**：两种输入顺序下输出均满足性质的比例。
  - **POH（Only One Has）**：仅一种顺序满足性质的比例，反映顺序方差。
  - **CWIO（Correlation With Input Order）**：输出数据单元顺序与输入顺序的 Kendall 相关系数。
- **评估方式**：对每个测试样本随机打乱输入顺序生成两个输入，检查输出的两个性质。

### 4. Rule Learnability（规则可学性）
- **定义**：从训练中学习并应用复制规则（将数据中的实体/数值直接复制到文本）的能力。
- **数据集构建**：
  - **WebNLG**：将被复制的实体替换为 "Entity i"。
  - **E2E**：将数值替换为 "Value i"。
- **评估方式**：在原始训练集上训练，在替换后的测试集上评估输出，结果分为四种情况 (a, b)：
  - a=1 表示隐藏信息被正确复制（模糊匹配），a=0 表示遗漏。
  - b=1 表示出现幻觉（输出被隐藏的实体/数值），b=0 表示无幻觉。
  - 仅 (1,0) 表示规则被正确应用，以其比例作为规则可学性指标。

### 关键公式
- **Chernoff 散度**：$\mathcal{D}(P, Q) = 1 - \sum_k p_k^{0.5} q_k^{0.5} \in [0,1]$，用于衡量两个数据集的分布差异。
- **Kendall 相关系数**：用于衡量输出顺序与参考顺序或输入顺序的一致性。

## 实验与结果
### 数据集
- **WebNLG+**：3,873 个 distinct triples，训练集 13,211 样本，测试集 2,179 样本（过滤后）。
- **E2E（清洗版）**：7 个 attributes，45 个 attribute-value pairs，训练集 6,735 样本，测试集 1,635 样本（过滤后）。

### 评测模型
- 小模型：T5-large (738M)、BART-large (406M)、GPT-2-large (774M)
- 大模型：T5-11b、Mistral-7b、Llama-2-13b
- 所有模型使用 LoRA 微调（r=8, α=32, dropout=0.1），学习率 1e-4，batch size=6，训练 10 epochs，beam width=5。

### 主要结果
| 维度 | 最强模型 | 关键发现 |
|------|----------|----------|
| **Systematicity** | T5-11b (WebNLG: 68.93, E2E: 53.78 on Atom) | 所有模型在 Atom 和 Combination 间存在显著性能差距；LLMs 优于小模型但未消除差距。 |
| **Productivity** | T5-11b (WebNLG N=3: 70.86) | 差距随 N 减小而增大；LLMs 整体更强但仍有不足。 |
| **Order Invariance** | T5-11b (Fidelity PBH: WebNLG 99.10%, E2E 99.28%) | Match 训练显著提高 CWIO 但降低 Proper Ordering 的不变性；整体模型在忠实性和排序上均存在缺陷。 |
| **Rule Learnability** | E2E 上 Mistral-7b/Llama-2-13b (~99%)，WebNLG 上 T5-large (89.32%) | WebNLG 上所有模型正确率<90%，主要错误为遗漏(0,0)；E2E 上小模型幻觉严重(0,1)。 |

### 评估指标
- **PARENT**：用于衡量输出质量（结合输入对齐和参考文本）。
- **PBH/POH/CWIO**：用于顺序不变性评估。
- **复制正确率**：(1,0) 情况的比例。

## 相关工作脉络
1. **Hupkes et al. (2020)**：提出组合泛化的多种表现（系统性、生产力等），本文将其引入 Data-to-Text 领域并扩展为四个维度。
2. **Keysers et al. (2020)**：提出基于重分配的综合评估方法，本文借鉴其思路但针对 Data-to-Text 的数据结构（三元组/属性值对）设计了专用算法。
3. **Mehta et al. (2022)**：仅在 Data-to-Text 中研究系统性，本文补充了生产力、顺序不变性和规则可学性三个维度。
4. **Wang et al. (2023)**：发现 LLMs 对多选题选项顺序敏感，本文进一步探究训练数据顺序一致性对顺序不变性的影响。
5. **Gehrmann et al. (2018)**：研究复制规则在 Data-to-Text 中的作用，本文设计评估方法量化模型对复制规则的遵循程度。
6. **Hu et al. (2022) LoRA**：参数高效微调技术，使小资源下微调 LLMs 成为可能，本文首次将 LLMs 纳入 Data-to-Text 组合泛化评测。

## 局限性与未来方向
1. **模型规模受限**：受计算资源限制，评测的 LLMs 最大为 13b，无法评估更大模型（如 70b+）的组合泛化能力。
2. **微调方式的局限**：未探索 In-Context Learning 风格下的组合泛化评估，该方法需考虑样本演示选择策略。
3. **数据集覆盖范围**：仅在 WebNLG 和 E2E 两个数据集上验证，其他 Data-to-Text 数据集（如 RobustLogic、DART）未涉及。
4. **评估任务的简化**：部分评估（如规则可学性）使用人工设计的替换策略，可能无法完全覆盖真实场景中的规则应用。

## 研究启发与可借鉴点
1. **基于重分配的数据集构建技巧**：Algorithm 1 和 2 的迭代选择与替换策略，可有效控制分布散度，适用于其他需要构造 held-out 组合的评测任务。
2. **多维度组合泛化评估框架**：将系统性、生产力、顺序不变性、规则可学性统一评估的方法论，可迁移至语义解析、程序合成等结构化到文本的任务。
3. **训练数据顺序一致性的负效应分析**：Match 训练集的构建揭示了数据预处理对模型顺序敏感性的影响，提醒研究者在数据构建时需考虑顺序随机化。
4. **模糊匹配规则评估设计**：规则可学性评估中允许语义等效复制（如忽略大小写、符号变化），提高了评估的鲁棒性，可借鉴于其他规则遵循任务。
5. **LLMs 在低资源任务中的能力边界探测**：通过 LoRA 微调将 LLMs 应用于 Data-to-Text，揭示其组合泛化缺陷，为后续改进提供明确方向。

## 关键术语表
- **Compositional Generalization（组合泛化）**：模型将已学习的元素按规则重新组合以处理新输入的能力。
- **Systematicity（系统性）**：处理训练期间未见过的数据单元组合的能力。
- **Productivity（生产力）**：处理输入数据量超过训练时所见最大长度的能力。
- **Order Invariance（顺序不变性）**：输入数据顺序改变时，输出保持数据忠实性和正确排序的能力。
- **Rule Learnability（规则可学性）**：从训练中学习并应用复制规则（将数据直接复制到文本）的能力。
- **PARENT**：针对 Data-to-Text 的评估指标，同时考虑输入对齐和参考文本相似度。
- **Chernoff Coefficient（切尔诺夫系数）**：用于衡量两个概率分布之间差异的指标，本文用于控制数据集构建的分布散度。
- **LoRA（Low-Rank Adaptation）**：参数高效微调方法，通过低秩矩阵适配预训练模型，本文用于微调 LLMs。
