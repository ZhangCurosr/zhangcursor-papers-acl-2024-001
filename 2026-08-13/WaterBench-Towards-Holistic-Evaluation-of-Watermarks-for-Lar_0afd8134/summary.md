# 论文速读：WaterBench-Towards-Holistic-Evaluation-of-Watermarks-for-Lar

## 一句话总结
本文提出了 **WaterBench**，首个针对 LLM 水印的全面评测基准，通过统一水印强度（TPR 对齐）的超参搜索流程，对检测性能与生成质量进行联合评估，并引入 GPT4-Judge 自动评测指令遵循能力的下降幅度。

## 研究问题与动机
- **两阶段任务的评估割裂**：现有水印研究大多将生成（generation）和检测（detection）分开评估，且未在统一超参数下进行公平比较，导致不同方法之间可能因水印强度不一致而产生误导性的排名。
- **单一数据集无法全面衡量生成质量**：先前评估多基于单一文本补全数据集（如 C4 RealNewsLike），无法覆盖多样化的 LLM 应用场景。
- **Perplexity 指标与人类偏好脱节**：现有工作普遍使用 perplexity 作为生成质量度量，在 LLM 时代与人类真实感受不一致，缺乏实用性。
- **缺少对指令遵循能力下降的系统性评估**：水印会改变 token 分布，是否损害 LLM 的核心能力（如指令遵循）尚无系统性量化评估。

## 核心贡献（创新点）
1. **提出统一水印强度的基准测试流程**：通过网格搜索调整各方法的超参数以达到相同 TPR（水印强度），再冻结超参进行联合检测与生成评估，解决了跨方法比较不公平的问题。与已有工作相比，本质区别在于将"水印强度"作为控制变量而非忽略它。
2. **构建覆盖 5 类任务、9 个子任务的多维度评测基准**：按输入/输出长度组合划分任务类别（短短/长短/长短短/长长/开放式），覆盖事实检索、长问答、推理、代码、摘要和指令遵循，弥补了之前仅用单一数据集的不足。
3. **引入 GPT4-Judge 自动评测指令遵循能力下降**：用水印后模型与 Davinci-003 的配对对比方式量化生成质量衰减，并结合人工评估验证（Cohen's kappa > 0.6），相比仅依赖 perplexity/ref-based 指标的既有工作更具实际意义。

## 方法详解
- **水印强度定义**：将水印强度定义为 TPR（True Positive Rate），即在给定阈值下水印文本被正确检测的比例，该值只依赖于水印算法和其超参数，与参考回答无关。
- **超参搜索流程**：对 Hard、Soft、GPT、V2 四类水印，以默认超参为起点进行网格搜索（调整 γ、δ 及 z-score 阈值），寻找能达到目标 TPR（0.95 或 0.7）的最接近超参组合，冻结后进行两阶段联合评测。
- **检测机制**：基于单比例 z 检验（Eq. 3），在生成文本的每个位置重新计算绿色列表，统计绿词占比并计算 z-score，超过阈值则判定为水印文本。
- **生成质量度量**：针对不同任务采用不同指标——F1（简短问答）、Rouge-L（长问答/摘要）、EditSim（代码）、GPT4-Judge（开放指令遵循），并在 AlpacaFarm 上进行 pairwise 对比评估。
- **五类任务分类**：按输入长度 × 输出长度的二维分类，每类两个子任务（共 9 任务 + 1 开放类 = 10 子任务），每任务 200 样本（除 AlpacaFarm 为 805）。

## 实验与结果
- **实验设置**：2 个 LLM（Llama2-7B-chat、InternLM-7B-8k）× 4 种水印（Hard/Soft/GPT/V2）× 2 个水印强度（TPR=0.95 和 TPR=0.7）。
- **关键发现**：
  - **检测性能**：TP 约 95%，TN 近 100%，说明当前水印检测方法有效且区分度高；但短答案任务（C1、C3）TP 显著更低（如 TP 从 90% 降至 0%）。
  - **生成质量**：所有水印均导致 GM 显著下降，硬水印在多数场景降幅超 50%；开放指令遵循任务（C5）下降超过 96%（GM 从 54.7 降至 1.1），GPT4-Judge 高度敏感。
  - **V2 水印表现最优**：在大多数任务类别中 GM 最高（TPR=0.95 整体 GM=11.2，降幅 60.3%），且 TN 亦优秀。
  - **模型差异性**：相同水印下 InternLM 的生成质量下降幅度大于 Llama2，说明存在模型特异性。
  - **强度对比**：TPR=0.7 时 V2 整体 GM=19.5，降幅仅 31.2%，明显优于其他方法。
  - **人工评估**：GPT4-Judge 与 3 位标注者 Cohen's kappa > 0.6，达到实质一致性。

## 相关工作脉络
- **LM Watermark (Kirchenbauer et al., 2023a)**：开创性工作，提出 Hard 和 Soft 两种水印机制；本文在其基础上构建统一评测基准。
- **V2 Watermark (Kirchenbauer et al., 2023b)**：改进版 Soft 水印，采用 LeftHash/SelfHash 和 WinMax 检测；本文实验中最优水印，凸显其鲁棒性优势。
- **Robust Watermark (Kuditipudi et al., 2023)**：关注对改写攻击的鲁棒性；本文未纳入主实验，留作后续工作。
- **GPT Watermark (Zhao et al., 2023)**：使用固定词汇组的简化方案以提升对编辑攻击的鲁棒性；本文评测发现其在检测上最强但生成质量不佳。
- **Unbiased Watermark (Hu et al., 2023)**：基于 Gumbel trick 的无偏水印；附录 B.4 补充评测发现其 GM 较高但 TP 不理想，进一步印证强度-质量权衡。
- **检测器方法 (Mitchell et al., 2023; Guo et al., 2023 等)**：基于黑箱分类器的检测方法；本文聚焦白箱推理时水印，二者路线不同。

## 局限性与未来方向
- **负样本仅为参考回答**：评测中只有参考回答作为负样本，而所有非水印文本理论上都可视为负例，覆盖不够全面。
- **每任务仅有一种生成指标**：未综合使用 Rouge-L、BertScore、FactCC 等多种度量全面评估不同维度的生成质量。
- **超参搜索仅取最接近点**：同一 TPR 下可能存在多种超参组合，本文仅报告偏差最小的那组，未探索 Pareto 前沿。
- **未考虑自适应水印强度方法**：如 NS-watermark 等自适应设置强度的方法不在讨论范围内。
- **GPT4-Judge 可能存在的偏差**：虽然有人工验证，但 LLM-as-a-judge 本身可能存在位置偏差或偏好漂移。

## 研究启发与可借鉴点
- **统一强度的评测框架**：将"水印强度"（TPR）作为控制变量的思路可迁移至任何需要公平比较不同算法的研究场景，避免超参不一致导致的误导性结论。
- **GPT4-Judge 在生成质量评估中的应用**：用 LLM 进行 pairwise 比较来评估指令遵循能力下降的方法，可作为通用评测范式应用于其他生成模型研究。
- **按输入/输出长度二维分类任务**：这种按信息容量维度组织评测任务的方法，可为其他 NLP 评测基准的设计提供模板。
- **超参网格搜索 + 阈值微调的两阶段搜索策略**：先调 γ/δ 再微张 z-score 阈值的流程兼顾效率与精度，值得在其他白箱方法评测中借鉴。
- **团队可结合的方向**：本文揭示了水印对指令遵循的严重损害（>96% 下降），团队可在"低损耗水印"或"自适应水印强度"方向提出改进方法，并以 WaterBench 为评测基准进行验证。

## 关键术语表
- **Watermarking Strength（水印强度）**：定义为 TPR，即水印文本被正确检测的比例，用于统一不同水印方法的比较基准。
- **Hard Watermark（硬水印）**：将词表划分为绿色/红色列表，解码时只能选择绿列表中的 token，是最原始的二进制水印方案。
- **Soft Watermark（软水印）**：在绿列表 token 的 logit 上添加常数偏移 δ，比硬水印更平滑，对生成质量影响较小。
- **V2 Watermark**：基于 Soft Watermark 的改进版，使用 LeftHash/SelfHash 哈希方案和 WinMax 检测统计量，对改写得鲁棒。
- **GPT Watermark**：使用固定词汇组而非动态哈希，简化流程并提高对编辑攻击的鲁棒性。
- **GPT4-Judge**：利用 GPT-4 作为评判器，对同一指令下两个模型生成的文本进行 pairwise 偏好选择，用于自动评估生成质量。
- **z-score Detection（z 分数检测）**：基于单比例 z 检验，统计生成文本中绿词占比偏离期望的程度来检测水印。
- **TPR / TNR**：True Positive Rate（真正例率）和 True Negative Rate（真负例率），分别衡量水印文本被正确检出和非水印文本被正确拒检的比例。

## 可复现要素
- **数据集**：WaterBench 由 KoLA、Copen、ELI5、FiQA、HotpotQA、LCC、MultiNews、QMSum、AlpacaFarm 等多个公开数据集的子集组成，均已获得授权许可；代码和数据已开源（https://github.com/THU-KEG/WaterBench）。
- **代码/权重**：评测代码开源；使用的是公开模型 Llama2-7B-chat 和 InternLM-7B-8k。
- **关键超参**：采样参数 temperature=0.7、top-p=0.9、top-k=0；z-score 阈值默认 4（TPR=0.95 时各方法微调至 3.2–4.3 范围）；γ（绿词比例）和 δ（logit 偏移）通过网格搜索确定，具体值见 Table 6。
